## Suggested learning path

1. Learn the [fundamentals](getting-started/fundamentals.md) and [Editor workflow](getting-started/editor-workflow.md).
2. Study [scripting](scripting/scripting.md), the [component catalog](api/components.md), and the [core API](api/core.md).
3. Follow either the [2D](2d/overview.md) or [3D](3d/overview.md) path for your project.
4. Use [recipes](recipes/recipes.md), [debugging](quality/debugging.md), and [performance](quality/performance.md) while building.
